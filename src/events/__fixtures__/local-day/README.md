# IANA local-day reference

Source: IANA tzdata2026c, https://data.iana.org/time-zones/releases/tzdata2026c.tar.gz.
Generated by `python3 scripts/time/fetch-local-days.py`, which caches the download
in the temporary directory, compiles the source using zic, and independently
walks Python zoneinfo calendar dates. Boundaries are refined to whole seconds.
No Celestine function or JavaScript Intl result generates expectations.

This checkout used `python3 scripts/time/fetch-local-days.py --local` because
network DNS was unavailable. This compiles the installed IANA source
`/usr/share/zoneinfo/tzdata.zi`, asserting its version is 2026c; it does not use
precompiled host zoneinfo files. UTC calendar tuples in iana.json are converted
to reference JDs in tests using Date.UTC / 86400000 + 2440587.5.

Fixtures live in `src/events/__fixtures__/local-day/`; tests are in
`src/events/local-day.test.ts`.

The per-zone rules and transition offsets are cited beside the tests. Monrovia
1972-01-07 switches at 00:00 local from −00:44:30 to UTC: its first existing
local time is 00:44:30. This exercises second-level transition bisection.
